# CompHelp AI SaaS Strategy

CompHelp AI starts as the operating system for one service business and expands into a SaaS platform for many service categories.

## Positioning

CompHelp AI is an AI Business Operating System for lead capture, CRM, estimates, dispatch, vendor coordination, project management, marketing, reporting, and developer operations.

## Initial Service Categories

- Computer repair.
- Security camera installation.
- WiFi and networking.
- Smart home setup.
- Data recovery.

These categories need fast response, trust, local SEO, clear estimates, before-and-after media, project tracking, and follow-up.

## Multi-Tenant Strategy

Each business is a tenant. Tenant data must be isolated with `tenant_id`, role-based permissions, and audit logs. Shared templates can be global, but customer, lead, project, invoice, message, and audit data must remain tenant-scoped.

## Agent Marketplace

Future agents can be packaged by industry:

- HVAC Estimate Agent.
- Roofing Inspection Agent.
- Plumbing Dispatcher.
- Property Manager Agent.
- Cleaning Route Planner.
- Local SEO Agent.
- Review Recovery Agent.

Each agent must declare tools, permissions, approval rules, outputs, and metrics.

## Go-To-Market Plan

1. Prove the operating system inside CompHelp AI.
2. Build local case studies.
3. Create reusable templates for adjacent service categories.
4. Sell to small service businesses that need faster response and better follow-up.
5. Add agency, vendor, and franchise partnerships.
