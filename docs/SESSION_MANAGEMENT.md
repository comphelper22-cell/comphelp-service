# Session Management

Sprint Epic 1 defines the session model without storing real sessions.

## Session Model

- Session ID
- Device
- Browser
- IP Placeholder
- Location Placeholder
- Last Activity
- Expiration
- Remember Me

## Defaults

- Session expiration: 60 minutes.
- Remember Me window: 30 days.
- IP and location remain placeholders until privacy and security policy are approved.

## Future Requirements

- Signed session token.
- Refresh-token rotation.
- Server-side revocation.
- Device history.
- Audit logging.
- Tenant-aware session validation.
