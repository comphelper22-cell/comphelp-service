# Known Limitations

## Beta Demo Limitations

- External services are not connected.
- Demo data is synthetic.
- Authentication is still internal admin-code based.
- Billing does not process real payments.
- Public API and integrations are architecture-only.
- Some AI modules use deterministic fallback logic instead of live AI provider calls.
- Supabase/PostgreSQL production migration is prepared but not fully connected for every module.

## Communication Rules

- Do not hide limitations.
- Do not present demo data as customer proof.
- Do not promise dates for unfinished features.
- Do not onboard real customer data without explicit approval and security review.
