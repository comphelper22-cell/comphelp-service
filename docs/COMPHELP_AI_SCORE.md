# CompHelp AI Score

The CompHelp AI Score is an internal product health score. It is not a public claim.

## Dimensions

- Strategy.
- Product.
- Customer Success.
- Performance.
- Reliability.
- Security.
- QA.
- Innovation.

## Grading

- 90-100: A.
- 80-89: B.
- 70-79: C.
- Below 70: Needs Review.

## Current Use

Project Titan Sprint Alpha uses safe default internal agent scores. Future sprints can connect the score to validation reports, performance checks, user feedback, and reliability metrics.
