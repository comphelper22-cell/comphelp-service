# Beta Demo Data

Beta Sprint 2 seeds `data/marketplace.json` with realistic Los Angeles service business records.

## Shared Source

The shared demo source is:

`data/marketplace.json`

The data is generated by:

`data/beta-demo-data.js`

CRM, Job Dispatch, Revenue Flow, Analytics, Dashboard, and AI Operations Assistant read this same JSON fallback data.
