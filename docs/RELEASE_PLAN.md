# Release Plan

## v0.7 Platform Foundation

Focus: organizations, users, RBAC, sessions, audit logs, notifications, preferences, and project control.

## v0.8 CompHelp Brain

Focus: approved shared memory, SOPs, decisions, lessons, knowledge retrieval, and privacy-safe context.

## v0.9 CRM Core

Focus: lead pipeline, customer timeline, project timeline, notes, search, filters, and task reminders.

## v1.0 Business OS MVP

Focus: usable end-to-end operating dashboard for leads, estimates, vendors, projects, follow-ups, reports, and quality gates.

## v2.0 SaaS Platform

Focus: multi-tenant SaaS, billing, tenant roles, templates, RLS, onboarding, and customer/vendor portals.

## v3.0 AI Agent Marketplace

Focus: installable agents, permissions, agent metrics, industry packs, and marketplace billing.
