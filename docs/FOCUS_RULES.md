# Focus Rules

- No new features during an active sprint unless the owner approves a scope change.
- New ideas go to `docs/IDEAS_BACKLOG.md`.
- Sprint changes require owner approval.
- Every sprint must pass CTO review.
- Every deploy must be approved.
- Every feature must create customer value.
- Validation must pass before commit.
- Do not push without approval.
- Do not deploy without approval.
- Do not add external automation during planning sprints.
