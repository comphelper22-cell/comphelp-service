# Revenue Flow Guide

The revenue flow supports Customer -> Estimate -> Approval -> Job -> Invoice -> Payment Status -> Revenue Dashboard.

No payment processor is connected and no card data is stored.

## Core Actions

- Create and edit estimates.
- Approve or reject estimates.
- Convert approved estimates to jobs.
- Create and edit invoices.
- Mark invoices sent, paid, or overdue.
- Record manual payment status.
- Review customer financial history.
- Review revenue dashboard and AI revenue recommendations.
